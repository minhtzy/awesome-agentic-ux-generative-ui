# Contributing

Thanks for improving this list.

## What belongs here

Add a protocol, runtime, design primitive, UX pattern, benchmark, or verified demo that directly supports agentic or generative UI.

## Entry rules

- Use the project's official documentation, repository, paper, or demo as the link target.
- Add one short sentence describing what it enables and how it relates to this list.
- Put an entry in its single best primary category; mention related categories in the description only when useful.
- Label research, prototypes, and experimental projects honestly.
- Do not add projects solely because they use an LLM; the UI/agent interaction must be central.
- Keep descriptions neutral and avoid unsupported claims about production readiness.

## Review checklist

- Link resolves and is a primary source.
- Description is specific enough to distinguish Text-to-Code from Text-to-Hydration.
- Runtime claims mention streaming, hydration, or code generation accurately.
- Safety-sensitive patterns include an approval, permission, or recovery boundary.
- README and `llms.txt` remain aligned for canonical entries.

## Pull requests

Keep one coherent addition per pull request. Explain why the resource belongs, identify its maturity, and include a screenshot/GIF only when you have permission to redistribute it.
