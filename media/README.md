# Demo media

Use this directory for screenshots, short GIFs, or diagrams that demonstrate a listed pattern or runtime.

- Prefer WebP/PNG for stills and optimized GIF/WebM for motion.
- Name files with the project and behavior, for example `tambo-tool-call-card.webp`.
- Include source, capture date, and redistribution permission in the pull request.
- Do not commit user data, secrets, or unlicensed product screenshots.
- Link media from the relevant README entry; do not add decorative assets without explanatory value.

The starter repository contains no demo media yet.
